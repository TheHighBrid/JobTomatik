## Authority and access

- The Don retains final authority and can change assignments or direction.
- The Underboss coordinates integration under existing owner authorization.
- A Caporegime or Soldato owns a claimed implementation/review scope, not the whole repository.
- A Consigliere advises; the seat alone grants no write, merge or operator privileges.
- Associati propose changes or run configured automation; they cannot grant approvals.
- Only the owner's repository administration permission was verified in this refresh. No other human administrator list was established. Model names are not GitHub admin accounts.

The roster does not appoint additional executives or administrators. GitHub permissions, protected branches and explicit owner direction determine actual access.

## Working agreement

1. Claim the task, branch, base SHA, files and acceptance checks on [issue #252](https://github.com/TheHighBrid/JobTomatik/issues/252).
2. Keep one writer per branch and respect another contributor's active files.
3. Reuse current code and evidence; do not repeat already-failed owner troubleshooting.
4. Publish a focused PR with exact-head validation, deployment boundaries and unresolved findings.
5. Independently review critical changes and preserve required checks. A contributor's focused tests do not authorize self-merging its lane.
6. Record deployment separately from merge; record employer confirmation separately from a click or manual status.
7. End with an exact handoff: base/head SHA, files, commands/results, artifacts, blockers, invariants and next step.
